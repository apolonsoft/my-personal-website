### Task 02: FastAPI Python Worker Scaffold & Config
- [x] Completed

#### Full Description
Create the `apps/api/` Python Worker project scaffold targeting Cloudflare Python Workers (Pyodide, Python 3.12), including dependency management via `uv`, Wrangler configuration with D1 and R2 bindings, environment/secret settings, Bearer token authentication dependency, ASGI entrypoint (`workers.asgi`), and the `/api/health` endpoint with its first `pytest` test suite.

#### Technical Instructions
1. Create `apps/api/.python-version` containing `3.12` so `uv` provisions a Python 3.12 environment matching Cloudflare's Pyodide runtime.
2. Create `apps/api/pyproject.toml`:
   - `requires-python = ">=3.12,<3.13"`
   - Runtime dependencies: `fastapi>=0.115.0`, `sqlmodel>=0.0.22`, `alembic>=1.14.0`, `sqlalchemy-cloudflare-d1>=0.3.0`, `python-multipart>=0.0.12`.
   - Dev/dependency-group dependencies: `workers-py`, `pytest>=8.3.0`, `httpx>=0.28.0`.
   - Configure `[tool.pytest.ini_options]` with `pythonpath = ["."]` and `testpaths = ["tests"]`.
3. Create `apps/api/wrangler.jsonc`:
   - `name`: `"my-personal-website-api"`
   - `main`: `"src/main.py"`
   - `compatibility_date`: `"2025-10-08"`
   - `compatibility_flags`: `["python_workers"]`
   - `d1_databases`: binding `"DB"`, `database_name`: `"personal-website-db"`, placeholder `database_id` (with comment explaining `wrangler d1 create`)
   - `r2_buckets`: binding `"IMAGES_BUCKET"`, `bucket_name`: `"personal-website-images"`
   - `vars`: `{ "ENVIRONMENT": "production", "R2_PUBLIC_BASE_URL": "" }`
   - `observability`: `{ "enabled": true }`
4. Create `apps/api/.dev.vars.example` with `API_ADMIN_TOKEN=dev-secret-token` and `DATABASE_URL=sqlite:///./local.db`.
5. Create `apps/api/src/__init__.py` and `apps/api/src/config.py`:
   - `Settings` dataclass/Pydantic model reading `API_ADMIN_TOKEN`, `DATABASE_URL`, `ENVIRONMENT`, and `R2_PUBLIC_BASE_URL` from `request.scope["env"]` (when running in Cloudflare Workers) or `os.environ` (when running locally/in pytest).
6. Create `apps/api/src/auth.py`:
   - `require_admin(request: Request, credentials: HTTPAuthorizationCredentials | None = Depends(HTTPBearer(auto_error=False)))` dependency using constant-time `hmac.compare_digest` against configured `API_ADMIN_TOKEN`. Raise `HTTPException(status_code=401, detail="Unauthorized")` if missing, invalid, or token unconfigured.
7. Create `apps/api/src/routers/__init__.py` and `apps/api/src/routers/health.py`:
   - `GET /api/health` returning `{"status": "ok", "service": "api"}`.
8. Create `apps/api/src/main.py`:
   - Instantiate `FastAPI(title="Personal Website Blog CMS API", version="0.1.0")` with CORS middleware configured cleanly.
   - Include `health.router`.
   - Conditionally bind `Default = asgi.entrypoint(app)` (wrapping `from workers import asgi` or `workers.Default` safely so local `pytest` imports succeed without the Cloudflare Worker runtime).
9. Create `apps/api/tests/conftest.py` and `apps/api/tests/test_health.py`:
   - Provide `TestClient(app)` fixture with test `API_ADMIN_TOKEN` set in `os.environ`.
   - Test `GET /api/health` returns `200` and `{"status": "ok", "service": "api"}`.
10. Run `cd apps/api && uv sync` and `uv run pytest -v`.
